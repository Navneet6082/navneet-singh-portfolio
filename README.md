# Navneet Singh - Professional Portfolio

Modern, responsive, high-performance portfolio website of **Navneet Singh** (B.Tech Computer Science & Engineering, Full Stack Web Developer & Software Engineer).

## 🌟 Tech Stack
- **Frontend**: Semantic HTML5, Modern CSS3 (Grid, Flexbox, Custom Properties, Glassmorphism), Vanilla JavaScript (ES6+)
- **Features**:
  - Dark / Light Mode with localStorage persistence
  - Interactive Filterable Project Showcase with accessible modal dialogs
  - Interactive Skills Matrix with category tabs
  - Flikt Technology Internship Experience Timeline
  - Embedded Downloadable Resume (`Navneet_Singh_Resume.pdf`)
  - Validated Contact Form with direct email integration
  - Print / PDF Resume layout (`@media print`)
